# X 关注巡检台

一个 Manifest V3 浏览器插件：粘贴 X 主页地址后，逐个检测当前关注状态；一键关注模式会在当前列表内按顺序最多关注 10 个未关注账号，超出部分标记为“待下批”，并记录最近一次批次时间。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，指向本目录。
3. 在 X 中登录后，点击工具栏里的“X 关注巡检台”。

## 使用

- 在输入框粘贴任意带有 X 链接的文本，支持序号、中文备注、换行、空格、半角或中文逗号；插件只提取链接中的账号名，并将 `/status/...` 推文地址还原为主页。
- “只检测状态”会读取所有地址的 Follow / Following 状态，不会点击按钮。
- “一键关注 10 个”会完整读取当前列表，但只点击前 10 个未关注账号；其余未关注账号显示为“待下批”。
- 任务在后台临时标签页执行，完成后标签页会自动关闭。列表与时间只保存在本地扩展存储中。
